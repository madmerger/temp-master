## 不一致 → 原因 → 対処

- TC-09（修正前）単一点の軸ラベル欠落・複数ラベル重複 → 自動目盛と衝突処理 → 63e469cで修正、再テストで点数1/2/3/4/5・regex一致・非重複・単一点中央を確認。
- TC-09（仕様差）旧Chart.jsとラベル集合・間隔が異なる → Swift Chartsの時間比例軸とgreedy間引き → 承認済み仕様差として点数・書式・非重複で評価。
- TC-14（修正前）137.6とAPI137.625の不一致 → 小数1桁への丸め → 63e469cで修正、137.625/50/300/50.0%を再確認。
- TC-18 legacy18台に対しiOS21台 → spec.md 34行のHub 3追加対応、差分3台は全てHub 3、旧18台の欠落無し → **仕様どおり（修正不要）**。厳密集合一致のみpass=falseを維持。
- TC-10 Refreshing...未捕捉 → POST500後の復帰が瞬間的 → actualはnull。指示に従いログ500・再取得200・最終Connected/エラー無しで合格。途中表示は保証しない。
- TC-16入力手順 → AX set_textは値を変えてもSwiftUI変更通知が発火しなかった → 末尾空白を実キーボード入力し、Importが有効化された後に実行。アプリバグと断定しない。
- 初回の画面外要素操作でLatencyへ意図しない遷移 → アクセシビリティ参照・自動スクロールの問題 → 可視画面と座標を確認し正式ケースとして再実行。
- TC-19の観測時刻差62秒 → キャプチャ操作の時間を含む → 無操作中の更新変化は確認済みだが、30秒周期の厳密計測は未実施。
